# Downloads Cleaner

Downloads Cleaner — desktop-приложение на Python для быстрой сортировки файлов в выбранной папке.

Программа определяет тип файла по его расширению и автоматически распределяет файлы по категориям.

Например:

```text
Downloads/
├── photo.jpg
├── document.pdf
├── archive.zip
├── music.mp3
└── setup.exe
```

После сортировки:

```text
Downloads/
├── Images/
│   └── photo.jpg
├── Documents/
│   └── document.pdf
├── Archives/
│   └── archive.zip
├── Audio/
│   └── music.mp3
└── Installers/
    └── setup.exe
```

## Основные возможности

* выбор папки для сортировки;
* определение категории файла по расширению;
* автоматическое создание папок;
* перемещение файлов по категориям;
* отдельная категория для неизвестных типов файлов;
* отображение результата сортировки.

## Категории

На первом этапе приложение будет поддерживать:

* Images
* Documents
* Archives
* Videos
* Audio
* Installers
* Other
